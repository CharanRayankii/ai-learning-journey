## Important Concepts

### Control Flow
- Conditional statements let code choose between different actions
- Loops allow repeating actions until a condition is met
- Nested logic is useful for more complex decision-making

### Practical Notes
- Keep conditions readable and avoid too much nesting
- Use `break` to exit loops early when the goal is reached
- Use `continue` to skip the current loop iteration
